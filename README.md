# keep-ios-apps-alive

Свои iOS-приложения на своём айфоне — в один клик. На каждое приложение — своя иконка `Install <Имя>.app`:
нажал, и на айфон встаёт свежая основная ветка проекта с GitHub, а бесплатная подпись Apple снова живёт 7 дней.

Без Automator, без сторонних зависимостей: только macOS, Xcode и системный `/usr/bin/python3`.

## Установка

```bash
git clone https://github.com/kudrmax/keep-ios-apps-alive.git
ln -s "$PWD/keep-ios-apps-alive/install-on-iphone" ~/.local/bin/install-on-iphone
```

Нужна папка из `PATH`; если `~/.local/bin` в нём нет, подойдёт любая другая или полный путь к скрипту.

## Приложения

```bash
install-on-iphone add ~/projects/my-app     # добавить и создать иконку (повторный add — обновить настройки)
install-on-iphone list                      # что настроено
install-on-iphone remove MyApp              # убрать из списка, иконку — в корзину
install-on-iphone sync                      # пересоздать все иконки (после обновления этого репозитория)
install-on-iphone run MyApp                 # поставить прямо в терминале, без иконки
```

Иконка появляется в `~/Applications` с картинкой самого приложения — её видно в Launchpad и Spotlight,
её можно перетащить в Dock. По нажатию открывается Terminal с ходом установки, в конце приходит уведомление.

Всё определяется само; флаги `add` — только когда автоматике не из чего выбрать:

| Флаг | Когда нужен |
|---|---|
| `--name` | своё имя иконки вместо имени Xcode-проекта |
| `--branch` | собирать не основную ветку (`main` или `master`) |
| `--scheme` | в проекте несколько схем, и ни одна не названа как проект |
| `--team` | в Xcode несколько команд разработчика |
| `--iphone` | с Mac сопряжено несколько айфонов |
| `--xcode` | выбрать Xcode вручную |

Список приложений — `~/.config/install-on-iphone/apps.json`, вне репозитория: в репозитории нет ни одного
названия проекта. В файле только то, что отличается от умолчаний, его можно править руками и потом сделать `sync`:

```json
{
  "apps": [
    { "name": "MyApp", "clone": "/Users/me/projects/my-app" },
    { "name": "Widgets", "clone": "/Users/me/projects/widgets", "scheme": "WidgetsApp", "iphone": "Work iPhone" }
  ]
}
```

Каждая иконка несёт свою копию установщика и своих настроек, поэтому после `git pull` этого репозитория нужен `sync`.

## Что происходит по нажатию

1. **Версия.** В папке проекта — только `git fetch` основной ветки. Ветки, HEAD и файлы не меняются: в этой же папке
   могут спокойно работать агенты. Ставится `origin/main` (или `origin/master`) — то, что на GitHub.
   Незапушенные коммиты и незакоммиченные правки в сборку не попадают; о незапушенных будет предупреждение.
   Нет сети — ставится та версия GitHub, что была при последней синхронизации.
2. **Айфон.** Сначала подключённый, из них — по проводу. Не отвечает по Wi-Fi — открывается Xcode, чтобы поднять
   соединение, и закрывается после установки, если до этого был закрыт.
3. **Временная папка.** На время установки — worktree основной ветки (только исходники, история остаётся в клоне)
   и папка сборки Xcode. Подмодули берутся из клона, без сети. Git-игнорируемые `*.xcconfig` (личная подпись)
   копируются из клона. После установки — и после ошибки тоже — всё уходит в корзину, git забывает worktree.
   На диске ничего не копится; цена — каждая сборка с нуля.
4. **Проект.** `.xcodeproj` из git, а если его там нет и есть `project.yml` — генерируется XcodeGen.
   Схема, приложение, bundle id и команда подписи читаются из `xcodebuild`. Из всех установленных Xcode берётся
   самый новый, который умеет собирать под этот айфон: у новых Xcode платформа iOS иногда не скачана.
5. **Подпись.** Xcode держит профиль подписи до конца его 7 дней, и переустановка их не продлевает.
   Поэтому закэшированные профили этого приложения и его расширений откладываются, и сборка получает новые:
   7 дней считаются с этой установки. Сборка упала — профили возвращаются, прошла — уходят в корзину.
   Без сети подпись не трогается: новую выдают только серверы Apple.
6. **Сборка и установка.** Release ставится поверх старой версии, данные приложения сохраняются.
   Полный лог неудачной сборки остаётся в `~/Library/Logs/install-on-iphone/`.

## Требования

- macOS, Xcode с вошедшим аккаунтом Apple (Xcode → Settings → Accounts), айфон хотя бы раз подключён проводом
  с «Доверять» и включённым режимом разработчика.
- У проекта есть `origin` на GitHub, и основная ветка хотя бы раз запушена или скачана.
- Для проектов на XcodeGen — `brew install xcodegen`.

## Разработка

```bash
/usr/bin/python3 -B -m unittest discover -s tests -t .
```

```
install-on-iphone      команда управления иконками
install_on_iphone.py   то, что запускает иконка
installer/
  cli.py               add / remove / list / sync / run
  registry.py          список приложений
  launcher.py          сборка Install <Имя>.app
  installer.py         сценарий установки
  source.py            git: fetch, временный worktree, подмодули
  xcode.py             проект, схемы, выбор Xcode, сборка
  devices.py           поиск айфона, установка
  profiles.py          обновление профилей подписи
  progress.py          строка прогресса в терминале
```
