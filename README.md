# install-on-iphone

Одна иконка на одно приложение: нажал — на айфон встаёт свежий `main` с GitHub.

## Создать иконку

```bash
/usr/bin/python3 make_app.py ~/projects/<проект>
```

Появится `~/Applications/Install <Имя>.app` с иконкой самого приложения. Её можно положить в Dock.
Если схем, команд подписи или айфонов несколько — `--scheme`, `--team`, `--iphone`. Другая ветка — `--branch`.
После правок в этом репозитории иконку нужно создать заново: код копируется внутрь неё.

## Что происходит по нажатию

1. В клоне проекта — только `git fetch`: ветки, файлы и HEAD не меняются, агентам ничего не мешает.
   Незапушенные коммиты в локальном `main` не попадают в сборку — об этом будет предупреждение.
2. Отдельная папка сборки (detached worktree) переключается на `origin/main`. Она и кэш сборки лежат
   в `~/Library/Caches/install-on-iphone/`; git-игнорируемые `*.xcconfig` (личная подпись) копируются из клона.
3. Схема, приложение, bundle id и команда подписи определяются через `xcodebuild`.
4. Айфон: сначала подключённый, из них — по проводу. Не отвечает — открывается Xcode и закрывается после установки,
   если до этого был закрыт.
5. Подпись: закэшированные профили этого приложения откладываются, чтобы 7 дней бесплатной подписи считались
   с этой установки. Сборка упала — профили возвращаются, прошла — уходят в корзину.
6. Release-сборка ставится поверх старой, данные приложения сохраняются.

## Тесты

```bash
/usr/bin/python3 -m unittest discover -s tests -t .
```
